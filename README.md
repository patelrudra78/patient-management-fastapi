# patient-management-fastapi
REST API for managing patient records with automatic BMI calculation and health verdicts. Built with FastAPI and Pydantic validation, with JSON file storage and a vanilla JS frontend.
A full-stack patient management app. The FastAPI backend provides endpoints to create, read, update, delete and sort patient records, validates input with Pydantic, and calculates BMI with a health category (Underweight, Normal, Overweight, Obese) for each patient. A lightweight HTML/CSS/JavaScript frontend lets you manage patients from the browser. Data is stored in a JSON file, and interactive API docs are available at /docs.

Note: all patient data in this repo is sample data.
